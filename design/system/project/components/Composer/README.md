# Composer

Where people ask Clerk something. Shows its context (the matter or selection) as a removable chip, accepts attachments and dictation, and sends with `↵` (`⌘↵` too). `⇧↵` starts a new line, and `↵` while an input method is composing only confirms the text.

The context chip makes scope explicit: Clerk only reads what the chip names. The footer line is fixed: “Clerk can be wrong. Check the citations.”, with the keys beside it (“↵ to send · ⇧↵ new line”).

Focus: the text area has no focus ring of its own. The box's border turns violet (`icon-ai`), which is the focus indicator, and a soft violet glow travels slowly round the border, about half of it lit (a conic gradient turning once every 6s). Under reduced motion the glow is still and even all round.
