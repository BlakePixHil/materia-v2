Other folders:

- `adr/`: architecture decision records. ADR-001 … ADR-020 summarise the decisions in `01-architecture-and-adrs.md`; ADR-021 onwards were added in feature PRs. New decisions start from `adr/0000-template.md`.
- `runbooks/`: operational runbooks, starting with `repo-setup.md`.
- `launch/`: the launch checklist (`checklist.md`, SEC-08): readiness with evidence, the runbook dry-runs, the go/no-go record and the post-launch review.
- `ops/`: performance and cost: the cost model for a target-scale firm (`cost-model.md`) and the performance reports (`perf-report-*.md`, SEC-07).

The ticket map is generated by `planning/build_ticket_map.py` in the legacy repo; regenerate it there rather than editing it by hand.
