# @materia/ui

Materia's Angular component library: design tokens, theme, icons and the `mt-*` components on ng-primitives (FND-07, FND-08). Usage and the component list are in [docs/03-design-system-and-ui.md](../../docs/03-design-system-and-ui.md).

- `nx test ui`: unit tests (Vitest and Angular Testing Library).
- `pnpm storybook`: Storybook on port 4400, with a light/dark theme switch.
- `nx run ui:test-storybook`: play functions and axe checks against a running Storybook.
